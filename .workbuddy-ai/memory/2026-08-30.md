
## 项目优化（Quest 3 设置 + 运行时性能 + 构建流程）

### 运行时性能改动（Assets/Scripts）
- `GradientFog`：LateUpdate 里每帧 4 次 `Shader.SetGlobalVector` 写的是常量 → 改为 `OnEnable`/`OnValidate` 一次性推送，并新增 `OnDisable` 清理（修复场景切换后残留上一场景雾色的 bug）。
- **关键发现**：`_FogDistance` / `_FogColorZenith` 等全局变量在 `Assets/Shaders/` 下**没有任何消费者**。`InkFog.shader` 用的是自己的材质属性（`_FogColor`/`_FogDensity`），且未被任何脚本引用。GradientFog 实际上是纯死代码，保留仅因未来可能用到。
- `WindSystem`：每帧 7 次 `SetGlobalFloat` → 拆分，3 个常量在 `OnEnable` 推送，每帧只更新 4 个动态值。
- `AudioMixerController`：每帧对常量做 lerp 并重复赋 `AudioListener.volume`，且结果无人读取 → 改为事件驱动 + 稳定后 early-return，新增 `AmbientVolume`/`SfxVolume` 属性暴露结果。
- `SceneBuilder`：新增 `Decorative()` + `DecorCube/Cylinder/Sphere/Plane`。`CreatePrimitive` 会给每个物件自动挂 Collider，竹林场景光叶子球就有 240+ 无用碰撞体（Plane 还会建 MeshCollider）。已应用于四个场景的叶簇/雾/月亮/远山/屋檐等装饰物。远山原本是场景中最大的 AABB 碰撞体。
- `MeditationPoint`：缓存 `.material` 实例，不再每帧读 `Renderer.material`。
- `MeditationLightPulse`：`FindObjectOfType<Light>()` 会抓到任意类型灯 → 改为优先 `RenderSettings.sun`。
- `VignetteEffect`：新增 `WantsRender`；配套新建 `Core/VignetteDriver.cs`（常驻组件，通过相机位移自驱，负责开关 effect）。解决问题：`SetMovementActive` 从未被调用，effect 一旦挂上就会每帧每眼做一次无意义全屏 blit，且 XRMenu 的 vignette 开关实际无效。

### 待办 / 风险
- **单通道实例化立体渲染（SPI）暂未启用**：所有 Gongbi 着色器均未声明 `UNITY_VERTEX_INPUT_INSTANCE_ID` / `UNITY_VERTEX_OUTPUT_STEREO`。GongbiToon 的 OUTLINE pass 是裸 vert/frag 直接读 `unity_ObjectToWorld`，开启 SPI 会导致双眼用同一视矩阵渲染（立体失效）且不报错。已将 SPI 逻辑放进 `Assets/Editor/OptimizeProject.cs` 的 `EnableSinglePassInstanced()`，带校验：着色器未打宏就拒绝开启并打印缺失清单。这是本项目剩余最大的渲染优化项。
- `Gongbi/InkFog` 着色器与 `GradientFog.cs` 目前无任何消费者，属死代码，可考虑删除。
- `AudioManager.asset` 的 `m_DSPBufferSize` 为 1024（Best performance，21ms 延迟），对冥想类应用可接受，未改动。

## 功能审计（产出 docs/FEATURE_PROPOSAL.md）

通读 Assets/Scripts（29 文件 / 3089 行）+ 4 个场景 .unity，核实出的**硬问题**（均可复核）：

1. **呼吸音效完全没接**：`BreathAudioSync.OnPhaseChanged` 全项目零调用点（死组件）；四个场景的 `MeditationPoint._breathAudioSource` / `_ambientAudioSource` 均为 `{fileID: 0}`。=> 冥想时听觉全程静默。
2. **XRMenu 在 Quest 上打不开**：`XRMenu.cs:47` 用 `Input.GetKeyDown(KeyCode.M)`，但项目 `activeInputHandler=2`（纯 Input System），legacy Input 不触发。
3. **呼吸稳定度是假指标**：`BreathGuide.RecordCycleDuration()` 读静态 `PatternTimings` 而非实测周期 => 方差恒 0 => `GetRhythmStability()` 恒返回 1.0，结算页永远显示 100%。
4. **结算页重复计数**：`SummaryScreen.cs:46` 与 `:52` 同用 `save.totalWalkingTime`，「本次步行」与「累计步行」显示同一个数。根因是 SaveManager 无 per-session 计时。
5. **`Pattern.Free` 名不副实**：`PatternTimings[3]` = `{6,2,8,0}`，和前三个一样是固定定时器。
6. **README/AGENTS 声称的 22 个 EditMode 测试不存在**：`Assets/Tests/` 是空目录，`Tests.csproj` 指向空目录。
7. 次要：`ComfortSettings` 从不调 `PlayerPrefs.Save()`（Quest 杀后台会丢设置）；`_breathCircleTransform` 是死字段。

其他缺口：全项目**零触觉反馈**；无传送移动（只有 smooth+snap）；无中文字体资源（`LegacyRuntime.ttf` 无 CJK，StartGate 只能显示英文）；坐/站高度硬编码 0.8/1.75m；`LocomotionController` 只轮询 `leftHandMoveInput`（右手摇杆无脚步声）+ 步长固定 0.8s 不随速度变；`BreathData.timeStampISO` 存了但完全没用（无 streak/历史）。
